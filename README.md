# Cat Facts API

## Project Setup Guide

This guide walks youthrough setting up te project on linux and mac machines

## Prerequisites
- A linux or mac system
- A bash or zsh terminal
- A local installation of go on your system
- A local installation of git on your system

## Installation Steps
1. Clone the github repository
```bash
git clone https://github.com/patrickishaf/cat_facts
```

2. Change into the project directory
```bash
cd cat_facts
```

3. Install dependencies
```bash
go mod tidy
```

4. Run the project
```bash
go run main.go
```
